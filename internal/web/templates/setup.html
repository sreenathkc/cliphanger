Retention

How long a finished job's still/clip and record stick around before being deleted automatically. Framewright keeps everything forever by default — set a number of hours here only if you want old jobs cleaned up on their own. Takes effect immediately, no restart needed.

Clip duration

How long a generated clip runs, for any job that doesn't specify its own spanSeconds (DemoFlex always sends its own, so this only matters for other/manual clients). A clip is a plain H.264 encode — no cross-frame trickery — so file size scales roughly linearly with duration.

Add a server

Click below, log into Plex in the tab that opens, and approve access. Framewright picks up the resulting token and your server's host/port automatically — nothing to find, copy, paste or type.

or enter details manually

Open the Plex Web App (app.plex.tv), go to any movie → the ⋯ menu → Get Info → View XML (bottom-left). A new tab opens — the token is in that tab's address bar, not the page text, as the part after X-Plex-Token= (up to the next & if there is one).

Kodi's web server has to be turned on first, on the Kodi box itself: Settings → Services → Control → Allow remote control via HTTP. Username/password below are only needed if you also enabled "Require authentication" on that same screen — leave both blank otherwise. Note: Kodi only serves files inside a configured source — a movie it can play isn't necessarily one it will hand over for extraction.

Optional fallback for the "outside a configured source" problem above. If Kodi's web server refuses to serve a file (401) because it's outside a source, and Framewright happens to have its own access to the same media (e.g. the same NAS share mounted separately), it can read the file directly instead of giving up — but only for that one situation; every other item still goes through Kodi normally. Fill in the two paths below only if you want this fallback: the path prefix as Kodi's own library reports it, and the prefix Framewright should replace it with. Leave both blank to skip this — nothing changes if you do.

In Jellyfin, go to Dashboard → API Keys, click +, give it a name like "Framewright", and paste the key it generates below. Unlike Plex, this key is scoped to the server admin who created it and can be revoked from that same page at any time.
