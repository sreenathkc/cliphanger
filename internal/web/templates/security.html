Security

Everything about who can get into ClipHanger — the API key clients use, and the optional local login for this web UI itself.

API key

Clients (like DemoFlex) send this in the X-Api-Key header. Rotating it immediately locks out anyone using the old one.

{{.APIKey}}

Local login

ClipHanger's web UI is open on your network by default — no login wall unless you turn one on here. Enabling this asks for a username and password every time this Setup/Jobs/Health/ Security UI is opened, even from inside your own network. It's separate from the API key above — that keeps working for DemoFlex and any other API client exactly as before, whether this is on or off.

Locked out? Stop the container, open store.json in your mounted data volume, set "localLoginEnabled": false, and restart.
